## Running Locally

Clone the repository:

```bash
git clone https://github.com/charlesk513/portfolio.git
```

Navigate into the project directory:

```bash
cd portfolio
```

Start a local development server:

```bash
python3 -m http.server 5500
```

Open the portfolio in your browser:

```text
http://localhost:5500
```
